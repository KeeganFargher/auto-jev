# Biome vignettes

The country a choice is about. A card offering "March on Tarn" shows the ground the army would walk
into, which is real information: mountains are slow, marsh is bad ground.

One file per biome, named for it: `grassland` · `forest` · `mountain` · `marsh` · `badlands`.

**3:4 portrait, 768×1024**, opaque. The picture fills the whole card and a black gradient covers the
bottom third, so keep the landscape's subject in the upper two thirds.

The five here are 8:3 panoramas from the first pass. They work — the card centre-crops them — but
only about a quarter of each is ever seen, so a 3:4 repaint would show far more of them.
